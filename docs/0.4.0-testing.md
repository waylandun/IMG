# Imageboard 0.4.0 测试说明

## 安装或升级

| 系统 | 安装文件 |
| --- | --- |
| macOS Apple Silicon（M 系列） | `Imageboard-0.4.0-mac-arm64.dmg` |
| macOS Intel | `Imageboard-0.4.0-mac-x64.dmg` |
| Windows x64 | `Imageboard-0.4.0-win-x64.exe` |

已有安装版：

1. 等待当前生成结束，关闭 Imageboard 页面并退出 Codex；让旧图片服务空闲退出（约五分钟）。
2. Mac 打开 DMG，将 Imageboard.app 拖入「应用程序」并替换旧版；Windows 运行 EXE，安装到原位置。
3. 运行新版 Imageboard 一次，完成注册，随后重新打开 Codex。
4. 点击左侧 Imageboard。若界面仍旧，右键入口选择「刷新」。

已有作品数据位于原数据目录，覆盖应用不会删除作品。不要从 DMG 内直接注册，须先复制到「应用程序」。完整步骤见 [INSTALL.md](../INSTALL.md)。

## 建议实测顺序

1. **输入框**：点击左侧「＋」，上传两张图片；再试粘贴、移除和多行输入。主输入框仅显示附件缩略图，生成设置折叠收纳。
2. **位置评论**：点击图片 → 添加评论 → 点击具体位置 → 输入要求 → Enter 或箭头保存。保存评论不发起生成；点击「发送」后，聊天消息带有图片和百分比坐标。
3. **调整大小**：菜单只含 1:1、3:4、9:16、4:3、16:9。图片内容完整保留，新增画布透明，评论位置同步换算。
4. **移除背景**：点击后自动关闭附件视图，把当前图片和固定提示词发送到聊天，显示生成进度和结果。确认主体完整、边缘自然、背景确为透明；可以测试「停止生成」。
5. **标注与擦除**：标注保存为参考图；擦除涂抹区域后由模型补全，选区外保留原图像素。
6. **历史与导出**：重新打开已发送附件查看只读评论，检查图片预览、下载及连续修改。

安装版使用现有 Codex API 配置。生成、去背景和擦除会调用真实模型；本地预览 `127.0.0.1:47826` 是模拟服务，适合检查交互，不代表真实生成效果。

## 已有验证与待验收范围

源码 43 项自动测试通过；上传、位置评论、固定比例、去背景聊天发送及取消已完成浏览器验证。打包后的验证结果记录在安装包目录的 `verification.json`。

macOS 使用现有 ad-hoc 签名，Windows 包未进行 Authenticode 签名。Windows 实机安装及真实模型效果仍需测试；自动验证不消耗真实生图额度。
