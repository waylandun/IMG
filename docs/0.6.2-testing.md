# 0.6.2 原图查看验证

0.6.2 保留生成中卡片、状态轮询和完成后原图展示。点击原图时优先调用 MCP Apps 的 `requestDisplayMode({ mode: "fullscreen" })`；宿主返回其他模式或不支持 fullscreen 时，卡片切换到自适应查看模式。退出按钮请求回到 inline。

本次移除了原图查看使用的 iframe 内部 `<dialog>`，避免卡片容器与 dialog 各自产生滚动条。原图查看不影响生成任务、下载、失败重试和最终聊天图片 Markdown。

验证结果：

- `npm test`：65 项通过。
- 模拟宿主：生成中显示、完成后加载、点击 fullscreen、返回 inline、原图读取失败重试均通过。
- 资源检查：创作卡片不再包含 `<dialog>`，包含 `requestDisplayMode` 通信；图片生成过程卡片保留。
- 已有作品与 MCP 图片传输流程未改变。

Codex 是否提供 fullscreen 由宿主的 `availableDisplayModes` 决定。宿主不提供时仍可在卡片内查看图片，最终聊天回复继续使用原生图片 Markdown。
