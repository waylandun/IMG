# Imageboard 0.4.1 测试说明

0.4.1 包含生成结果的半透明「编辑」按钮、左右分栏，以及共享图片工具中的局部重绘和扩图。

## 安装或升级

| 系统 | 安装文件 |
| --- | --- |
| macOS Apple Silicon（M 系列） | `Imageboard-0.4.1-mac-arm64.dmg` |
| macOS Intel | `Imageboard-0.4.1-mac-x64.dmg` |
| Windows x64 | `Imageboard-0.4.1-win-x64.exe` |

1. 等待当前生成完成，关闭 Imageboard 并退出 Codex；旧图片服务空闲约五分钟后退出。
2. Mac 打开 DMG，将 Imageboard.app 拖入「应用程序」并覆盖旧版；Windows 运行 EXE，安装到原位置。
3. 运行新版 Imageboard 一次完成注册，再重新打开 Codex。
4. 从 Codex 左侧进入 Imageboard；若仍显示旧界面，右键该入口选择「刷新」。

已有作品保留。不要直接从 DMG 内运行注册。完整说明见 [INSTALL.md](../INSTALL.md)。

## 本次建议实测

1. 生成一张图片，确认图片左下角有半透明「编辑」按钮。
2. 点击「编辑」，宽屏左侧保留聊天与输入框，右侧显示该图片及工具栏。
3. 确认右侧包含标注、添加评论、移除背景、擦除、调整大小，以及额外的局部重绘、扩图。
4. 点击「局部重绘」，涂抹或框选后应用，在左侧输入要求并发送；检查模型修改选区，原图保留。
5. 点击「扩图」，设置边距并应用，再发送补全需求；确认扩展方向及原图保留。
6. 一次生成两个方案，编辑第二个方案并发送评论，确认后续生成基于第二张图。
7. 再次点击正在编辑的同一方案，确认评论草稿不丢失；关闭高级编辑后仍可使用普通图片工具。
8. 普通上传附件仍仅显示原有五种工具。窄屏下使用全屏编辑，应用重绘或扩图后返回聊天。

安装版使用现有 Codex API 配置。生成、去背景、擦除及重绘/扩图会调用真实模型；`127.0.0.1:47826` 为模拟预览，不能用于判断真实生图效果。

## 验证范围

源码 43 项测试与浏览器模拟交互已通过。打包自检、完整性、架构及文件一致性结果见分发目录的 `verification.json`；安装包校验值见 `SHA256SUMS.txt`。

macOS 沿用 ad-hoc 签名；Windows 包未进行 Authenticode 签名，尚需 Windows 实机验收。真实模型效果由本次实际测试确认。
