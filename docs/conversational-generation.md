# 对话式生图（0.5.0）

Imageboard 0.5.0 保留单一聊天入口：模型结合上下文判断是继续讨论还是调用 `generate_image` 工具。需求清楚时直接生图，关键方向不清楚时先澄清；用户明确要求先讨论时只回复文字。

- `server/agents.mjs`：意图判断、聊天提示和生图工具协议。
- `server/conversations.mjs`：多轮会话、消息去重、恢复、取消和任务关联。
- `server/jobs.mjs`：继续负责实际图片生成、编辑、版本和结果保存。
- `web/app.js`：同一消息流展示讨论、进度、图片和连续修改。

当前 502 问题已确认来自渠道模型不可用，和上述对话流程代码无关。切换可用生图模型后即可继续使用 0.5.0 功能。
